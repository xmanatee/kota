# Route Key Task

The route-key output is generated by a Spool program over each case:

1. Read the `phrase` field.
2. Clean to uppercase base36 glyphs.
3. Apply the seed-indexed shift.
4. Reassemble characters through three seed-offset rails in south, north,
   middle order.
5. Append the weighted checksum.
6. Group the final tape in chunks of four with dots.

Visible examples live in `examples/visible-cases.json`. Hidden verifier cases
exercise punctuation removal, seed offsets, one-character tapes, and rail
boundary behavior.
