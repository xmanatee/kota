Usage: kota daemon [options] [command]

Run the KOTA daemon host and foreground dashboard.

Foreground daemon mode:
  This command hosts and monitors the daemon. It is not the interactive operator
console.
  Open the console with `kota navigate` or bare `kota`.
  Inspect and control workflow dispatch with `kota workflow status`, `pause`,
`resume`, and `follow`.
  Render the shared operator controls with `kota ui render operator-control`.

Options:
  -v, --verbose              Show debug output
  --preset <id>              Preset bundle (claude | codex | openrouter |
                             openrouter-lab | gemini | gemini-cli |
                             antigravity-cli). Overrides KOTA_PRESET and
                             config.defaultPreset for this daemon process
  --poll-interval <seconds>  Scheduler poll interval in seconds (default: "30")
  --project-dir <path>       Project directory the daemon operates on (overrides
                             KOTA_PROJECT_DIR env and cwd)
  --log-format <format>      Log format: text (default) or json
  -h, --help                 display help for command

Commands:
  start [options]            Start the KOTA daemon host and foreground dashboard
  status [options]           Show daemon health summary (exits 0 if reachable)
  pid [options]              Print the PID of the running daemon (exits non-zero
                             if not running)
  stop [options]             Gracefully stop the running daemon (exits 0 on
                             success)
  reload [options]           Reload daemon config and re-register module
                             workflow contributions without restart
  install [options]          Register the KOTA daemon as a user-level OS service
                             (launchd on macOS, systemd on Linux)
  uninstall                  Remove the KOTA daemon OS service installed by
                             'daemon install'
  qr                         Print a QR code encoding the daemon URL and auth
                             token for mobile client setup
