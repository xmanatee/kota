Security regression: scientific-claim analyzer host signaling

The production boundary verifier launches a detached, same-UID sentinel and an
analyzer that calls process.kill(sentinelPid, "SIGKILL"). It accepts the
boundary only when the analyzer receives EPERM/ESRCH and the sentinel is still
alive. The deterministic regression also proves a passthrough boundary is
rejected after delivering the signal, without exposing the evaluator process.

macOS boundary:
- sandbox-exec profile denies network* and signal.
- Both restrictions are capability-tested before analyzer execution.

Linux boundary:
- unshare creates user, network, PID, and proc/mount namespaces.
- --fork, --mount-proc, and --kill-child keep the analyzer inside the PID
  boundary and tear down its process tree on evaluator timeout.
- The same live network and host-signal probes must pass.
