# Review Scrutiny Escalator

Code-only monitor that turns recurring thin reviewer acceptances into one
evidence-backed repair task per stable pattern.

- Read only review-scrutiny artifacts and existing report aggregation inputs.
- Keep grouping deterministic: reviewer surface, workflow, task area, and task
  class where available.
- Treat unsupported artifacts and absent metrics as context, not standalone
  proof of poor review.
- Keep operator visibility in reports and `workflow.attention.digest` without
  cost fields.
